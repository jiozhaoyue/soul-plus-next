## 正文一 · 规则条目（R-01~R-24）

- **R-01** 零臆测 + 检索先行双通道：凡技术事实先 WebSearch/WebFetch 与 GitHub API 双通道检索，不脑补不碰运气。
- **R-02** 全中文思维链与产出：一切内部思考、推导、汇报、文档、注释均用中文，仅标识符与专有名词例外。
- **R-03** 单命令 ≤10 秒硬死线：前台命令超过 10 秒即判失败，不得原样重试，须降级或转后台。
- **R-04** 非阻塞全并行与长任务后台化：独立命令一次性并发发出，构建/安装/大批量测试一律后台化。
- **R-05** 禁等待型命令与无界递归扫描：禁 sleep/timeout/tail -f/死循环，禁全盘 find、全局 grep -r。
- **R-06** 强制 diff 工具、禁终端写源码：变更用块级 diff/Edit，禁重定向、cat heredoc 写源码。
- **R-07** 全程出声：工具前报备在做什么/看到什么/下一步，写配置先报绝对路径+内容+原因并读回校验。
- **R-08** 交互问答聚合提问 + 重大决策主人裁定：关键问题一次性聚合提问，架构与破坏性决策等主人拍板。
- **R-09** 计划先行、PRD 不留 TBD、实时勾选：多步骤改动先落盘计划与验收标准，进度随做随勾。
- **R-10** 可选后端适配器：引入服务端能力时用适配器+特性检测+静默降级，前端主路径保持闭环。
- **R-11** 高风险操作显式授权门禁：删除/覆盖/装包/重构/意图歧义前先报备并取得明确授权。
- **R-12** 凭据脱敏与密钥外置：密钥凭据不落盘不入库，一律外置并在日志与输出中脱敏。
- **R-13** 前端零 CDN、单文件、file:// 兼容：禁止运行时外部 CDN 脚本样式，资产本地离线自包含。
- **R-14** UI 文本产品化、禁元文本：界面不出现开发说明/TODO/免责声明，文案精炼面向动作。
- **R-15** 禁 AI slop 套路：用设计技能链，禁千篇一律配色，交付前真实截图自检盒模型与布局。
- **R-16** 禁内置预览通道：前端验证用系统独立服务进程 + 自动化脚本取真实渲染数据，不用 IDE 简易预览。
- **R-17** 禁 AI 自测与自拟提示词互喂：不做效果对照评测，只执行主人明确指定的业务路径。
- **R-18** 共享知识仓私有远程、每次提交即推送：统一规则与核心资产仓建私有远程，提交即同步推送。
- **R-19** 子代理蜂群规范：任务自包含、一文件一写者、非阻塞并发、禁消息板中转、红队必派、三级派发顺序。
- **R-20** mini-trellis 记忆层规范：真源与摘要分层，详情经 mem recall 命中，摘要指向唯一真源。
- **R-21** 代码复用与跨层思维：先 grep 复用现成方案，重复 2 次以上抽 guard，35% 误报率回查。
- **R-22** 规则单一真源 + 索引 + 短注入生成物禁手改：真源唯一，索引可达，生成物只由流程再生。
- **R-23** 事实先于结论：完成需可复现证据（命令+输出），禁报喜不报忧，未验证项如实标注。
- **R-24** 测试全绿零回归：异步任务有界、失败不静默，改动不引入既有功能回归。

## 正文二 · 铁令条目（M-01~M-05）

- **M-01** 模型钉死 hy4-flash-free：zcode 子代理唯一合法档位为 new-provider/opencodego/hy4-flash-free，输入输出零成本。

- **M-03** API 链接 8317/15721 不动：涉及该端口链接的配置保持原样，禁止改动。

- **M-05** agy native swarm 为对等平台：等价遵循蜂群规范，与 zcode 工作流地位对等。

## 正文三 · 工具/操作条目（T-01~T-07，独立条目）

- **T-01** 删除走回收站归档 + Git 显式 pathspec：删除先归档可恢复，git 操作只用显式路径，不批量不隐删。
- **T-02** 脚本禁硬编码业务数据：业务数据外置配置，脚本只保留逻辑，不放死值。
- **T-03** 脚本中控与仓内脚本目录：脚本统一收敛到仓内约定目录，由中控调度，不散落。
- **T-04** 工作流改动覆盖五面留证据：改工作流须覆盖文档/配置/索引/摘要/记忆五面并留可复现证据。
- **T-05** 交互输出物理分行：多段信息物理分行呈现，不堆砌在一行，便于阅读核对。
- **T-06** 对话正文不贴完整文件：只给路径与关键片段，不在正文粘贴整份文件。
- **T-07** 禁破坏性 git 回滚未提交改动：不随意 reset/checkout 丢弃未提交内容，回滚前先确认可恢复。
